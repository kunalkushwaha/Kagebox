# Profile: dev — research, plus the registries a coding agent needs.
#
# This is a deliberately looser posture and you should know what it costs.
# Package registries are the sharpest edge here, in both directions:
#
#   * They accept uploads. An allowlisted registry is a publish endpoint, and
#     publishing is exfiltration with extra steps.
#   * Installing a package RUNS its code inside the VM. The sandbox contains
#     that, which is the point — but "contained" is not "harmless", and a
#     malicious dependency now has your allowlist to work with.
#
# Use it when the agent is writing code against sources you trust. For reviewing
# an unfamiliar repository, or anything that arrived from outside, drop back:
#   ./kagebox egress profile sealed   (or use ./kagebox task, which forces it)
